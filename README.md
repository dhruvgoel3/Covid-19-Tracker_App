# COVID-19 Tracker App



📌 Overview

The COVID-19 Tracker App is a Flutter-based application that provides real-time statistics on COVID-19 cases across the world. The app fetches global and country-wise COVID-19 data, including total cases, deaths, and recovered numbers. Currently, the data is static, but future updates will integrate real-time API updates.

🚀 Features

🌍 Global COVID-19 Statistics (Total Cases, Deaths, and Recovered)

📊 Country-wise Data (Search and view stats for specific countries)

⚡ Fast & Responsive UI with an intuitive design

🔍 Lightweight & Efficient for smooth performance
